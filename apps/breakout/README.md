# BRICK BLITZ

1976年に登場した古典的なブロック崩しゲームへのオマージュとして独自に実装した、非公式ファンメイド PWA です。
特定の商標名は使用していません。

## 遊び方

1. 画面をタップ(またはFIRE/LAUNCHボタン / Space / Enter)でスタート
2. パドルを左右に動かしてボールを操作する
   - 左右ボタン、キーボードの ←→(A・D)
   - または画面を直接ドラッグ(タッチ操作に最適)
3. ボールはパドルに乗った状態からスタート。LAUNCHボタン(またはSpace / Enter)で発射
4. パドルの端に当てるほど、ボールは斜めに強く跳ね返る(狙って打ち分けられる)
5. 全てのブロックを壊すとレベルクリア。レベルが上がるほどボールが速くなる
6. ボールを落とすとライフが1減る。ライフが無くなるとゲームオーバー
7. ⏸ PAUSEボタン(またはキーボードの `P`)でいつでも一時停止/再開
8. 最高得点は端末に保存され、次回スタート時に表示される

## 技術構成

- 素のHTML / CSS / JavaScript(ビルド不要、フレームワーク依存なし)、描画は Canvas 2D
- ゲームロジック(`js/game.js`)は描画・DOMに依存しない純粋な状態machineとして実装し、Node上で直接ユニットテスト可能
- PWA対応(`manifest.json` + `sw.js` でオフライン動作・ホーム画面追加に対応、ネットワーク優先キャッシュ戦略)
- 外部ライブラリ・フォント・画像アセットのネットワーク依存なし

```
breakout/
  index.html
  css/style.css        筐体・HUD・操作ボタンのスタイル
  js/
    game.js             ゲームロジック(描画非依存、テスト対象)
    render.js             Canvas描画
    app.js                 ゲームループ・入力(ボタン/キーボード/ドラッグ)・サウンド・PWA登録
  manifest.json / sw.js  PWA設定
  test/                  ロジックの回帰テスト(フレームワーク無し)
```

## ローカルでの動作確認

```bash
npm run dev
```

## テスト

```bash
npm test
```

## 既知の簡略化

- ブロックは6行×8列の固定レイアウト(パターン変化なし)
- パワーアップ・マルチボールなどは未実装(原型のシンプルなルールに準拠)
- スコア配点・速度上昇カーブは独自のバランス調整
