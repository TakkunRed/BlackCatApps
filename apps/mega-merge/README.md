# MEGA MERGE

オリジナルのパズル×シューティングゲームです。ブロック崩しのように並んだ「2の累乗」の数字ブロックを下から撃ち、
2048を目指して合体させていきます。特定の既存ゲームの移植・模倣ではなく、独自に考案したルールです。

## 遊び方

1. 画面をタップ(またはFIREボタン / Space / Enter)でスタート
2. 自機を左右に動かして狙う列を決める
   - 左右ボタン、キーボードの ←→(A・D)
   - または画面を直接ドラッグ
3. FIREボタン(またはSpace / Enter)で弾を発射。自機弾は同時に1発まで
4. 弾が当たったブロックの数字が**2倍**になる
5. そのとき、上下左右の隣接ブロックに同じ数字があれば**合体してさらに2倍**(優先順位: 上→右→下→左)。
   合体後の数字がまた隣と一致すれば連鎖し、連鎖が長いほど得点ボーナスが大きくなる
6. **2048に到達したブロックはポップして消滅**する
7. 合体やポップで空いたマスには、同じ列の上にあるブロックが**重力で落ちてくる**。
   どの列を撃つかで盤面の並びが実際に作り変わっていく
8. **列が完全に空になると、左右の列が詰まって隙間が無くなる**。盤面が進むほど残ったブロック同士が
   自然に近づくので、終盤でも「打つしかない」状態になりにくい
9. **弾は130発まで**。盤面(6×6)を全て消す前に撃ち尽くすと **OUT OF AMMO** でゲームオーバー
10. 盤面のブロックを全て消すと **ALL CLEAR**
11. ⏸ PAUSEボタン(またはキーボードの `P`)でいつでも一時停止/再開
12. 最高得点は端末に保存され、次回スタート時に表示される(クリアできなくても、その回のスコアが新記録なら更新される)

v1は「同じマスを撃ち続ければ必ず勝ててしまう」設計だったため(プレイヤーの選択がほぼ結果に影響しないことをシミュレーションで確認)、
v2で**重力落下**と**弾数制限(130発)**を追加しました。重力により「どの列を撃つか」が盤面を実際に作り変えるようになり、
シミュレーションでは1手先読み戦略で平均105発・ランダム戦略で平均161発という有意な差が出ています。
弾数上限130発は、先読み戦略の成功率95%・ランダム戦略の成功率6%になるよう調整した値です。

v2.1では、実際に遊んだフィードバックを受けてさらに2点改善しました。

- **合体の過程が見えなかった問題**: それまでは連鎖・重力・列詰めが一瞬で結果だけ反映されていたため、
  「何が起きたか分からない」「連鎖しているかも分からない」状態でした。ロジック自体は即時確定のまま、
  起きたことの詳細(どの位置が合体したか・何が何マス落ちたか・どの列がどこへ詰まったか)を記録し、
  画面側でその記録を順番に再生する形でアニメーション化しています。
- **終盤・列が孤立すると「打つだけ」になる問題**: 重力が列の中だけで完結していたため、隣の列が
  無くなるとそれ以上合体のしようがありませんでした。列が完全に空になったときに左右の列を詰める
  処理を追加し、残りが少なくなるほど自然に隣接のチャンスが生まれるようにしています。

## 得点ルール

各合体ステップの得点 = そのステップで到達した数字 × (1 + 連鎖回数 × 0.5)。
たとえば合体なしの直撃は等倍、1連鎖なら1.5倍、2連鎖なら2倍…と、連鎖が伸びるほど
「数字の指数的な伸び」と「連鎖ボーナスの線形な伸び」が掛け合わさって得点が跳ね上がる設計です。
2048へのポップ時はさらに固定ボーナスが加算されます。

## 技術構成

- 素のHTML / CSS / JavaScript(ビルド不要、フレームワーク依存なし)、描画は Canvas 2D
- ゲームロジック(`js/game.js`)は描画・DOMに依存しない純粋な状態machineとして実装し、Node上で直接ユニットテスト可能
- PWA対応(`manifest.json` + `sw.js` でオフライン動作・ホーム画面追加に対応、ネットワーク優先キャッシュ戦略)
- 外部ライブラリ・フォント・画像アセットのネットワーク依存なし

```
mega-merge/
  index.html
  css/style.css        筐体・HUD・操作ボタンのスタイル
  js/
    game.js             ゲームロジック(描画非依存、テスト対象)
    render.js             Canvas描画(数字・色分け)
    app.js                 ゲームループ・入力(ボタン/キーボード/ドラッグ)・サウンド・PWA登録
  manifest.json / sw.js  PWA設定
  test/                  ロジックの回帰テスト(フレームワーク無し)
```

## 既知の簡略化・今後の案

- 今後の拡張案として、ブロック全体が徐々に降りてくる「降下モード」も検討可能(現状、重力は列の中だけ・列の詰めは水平方向のみ)
- 初期盤面はランダム生成(2,2,2,4,4,8の重み付き抽選)。特定のパズルが必ず解けることは保証していない
- 弾数上限(130発)・連鎖ボーナス倍率・ポップ閾値(2048)は、いずれもシミュレーションを根拠にした調整値で、今後のバランス変更の余地がある
- アニメーション中は演出を最後まで見せるためFIRE入力を一時的に無視する(連打しても弾は消費されない)
