# GALAXY SIEGE

1978年に登場した古典的な固定画面シューティングゲームへのオマージュとして独自に実装した、非公式ファンメイド PWA です。
特定の商標名・スプライト画像は使用せず、ゲームシステムの再現と独自制作のピクセルアートで構成しています。

## 遊び方

1. 画面をタップ(またはFIREボタン / Space / Enter)でスタート
2. 左右ボタン(またはキーボードの ←→ / A・D)で自機を移動
3. FIREボタン(またはSpace / Enter)で弾を発射。自機弾は同時に1発まで
4. 編隊は左右に移動しながら少しずつ自陣へ近づいてくる。全滅させるとウェーブクリア
5. インベーダーがシールドのラインまで到達すると即ゲームオーバー
6. ライフが無くなってもゲームオーバー
7. 時々現れるUFOを撃つとボーナス得点
8. シールド(砦)は被弾した部分から少しずつ欠けていく
9. ⏸ PAUSEボタン(またはキーボードの `P`)でいつでも一時停止/再開
10. 最高得点は端末に保存され、次回スタート時に表示される

## 技術構成

- 素のHTML / CSS / JavaScript(ビルド不要、フレームワーク依存なし)、描画は Canvas 2D
- ゲームロジック(`js/game.js`)は描画・DOMに依存しない純粋な状態machineとして実装し、Node上で直接ユニットテスト可能
- PWA対応(`manifest.json` + `sw.js` でオフライン動作・ホーム画面追加に対応、ネットワーク優先キャッシュ戦略)
- 外部ライブラリ・フォント・画像アセットのネットワーク依存なし(ピクセルアートもコードで描画)

```
space-invaders/
  index.html
  css/style.css        筐体・HUD・操作ボタンのスタイル
  js/
    game.js             ゲームロジック(描画非依存、テスト対象)
    sprites.js           ピクセルアート定義(左右対称の半幅パターン)
    render.js             Canvas描画
    app.js                 ゲームループ・入力・サウンド・PWA登録
  manifest.json / sw.js  PWA設定
  test/                  ロジックの回帰テスト(フレームワーク無し)
```

## ローカルでの動作確認

```bash
npx --yes serve .
```

## テスト

```bash
node test/game.test.mjs
```

## 既知の簡略化

- 編隊は5行×8列(オリジナルの5行×11列より少し小ぶり)
- シールドはウェーブ開始時にリセットされる(ダメージは引き継がない)
- スコア配点・UFO出現間隔・難易度カーブは独自のバランス調整
