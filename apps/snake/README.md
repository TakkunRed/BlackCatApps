# SNAKE BYTE

古典的なスネークゲームへのオマージュとして独自に実装した、非公式ファンメイド PWA です。
特定の商標名は使用していません。

## 遊び方

1. 画面をタップ(またはいずれかの方向キー / Space / Enter)でスタート
2. 方向を変えてヘビを操作する
   - 画面下の方向ボタン(▲▼◀▶)
   - キーボードの矢印キー / WASD
   - 画面を直接スワイプ
3. 食べ物(赤)を取るとヘビが伸び、加点される。食べるほど少しずつ速くなる
4. 壁、または自分の体にぶつかるとゲームオーバー
5. 自分の体への即Uターン(逆走)はできない仕様
6. ⏸ PAUSEボタン(またはキーボードの `P`)でいつでも一時停止/再開
7. 最高得点は端末に保存され、次回スタート時に表示される

## 技術構成

- 素のHTML / CSS / JavaScript(ビルド不要、フレームワーク依存なし)、描画は Canvas 2D
- ゲームロジック(`js/game.js`)は描画・DOMに依存しない純粋な状態machineとして実装し、Node上で直接ユニットテスト可能
- PWA対応(`manifest.json` + `sw.js` でオフライン動作・ホーム画面追加に対応、ネットワーク優先キャッシュ戦略)
- 外部ライブラリ・フォント・画像アセットのネットワーク依存なし

```
snake/
  index.html
  css/style.css        筐体・HUD・方向ボタンのスタイル
  js/
    game.js             ゲームロジック(描画非依存、テスト対象)
    render.js             Canvas描画
    app.js                 ゲームループ・入力(ボタン/キーボード/スワイプ)・サウンド・PWA登録
  manifest.json / sw.js  PWA設定
  test/                  ロジックの回帰テスト(フレームワーク無し)
```

## ローカルでの動作確認

```bash
npm run dev
```

## テスト

```bash
npm test
```

## 既知の簡略化

- フィールドは24×28マスの固定グリッド(壁抜け・ワープなし)
- 食べ物は常に1個だけ出現する(複数出現や特殊アイテムは無し)
- 速度上昇カーブ・得点配点は独自のバランス調整
