# 電卓インベーダー (Calculator Invader)

CASIO の「ゲーム電卓 SL-880」([公式製品ページ](https://www.casio.com/jp/basic-calculators/product.SL-880/)) へのオマージュとして、
電卓UIの上にそのシューティングゲーム「デジタルバトルゲーム」を独自実装した非公式ファンメイド PWA です。
CASIO 社とは関係ありません。中身(計算ロジック・ゲームロジック・UI)はすべて独自実装です。

## 遊び方

1. **GAME** ボタンでゲームモードに入る
2. インベーダー(数字 0〜9、たまに UFO = `n`)が**複数同時に列をなして**自陣(左側)に向かって接近してくる
3. **•(AIM)** ボタンを押して照準の数字をインベーダーの数字に合わせる(0→1→…→9→n→0…と循環)
4. **+(FIRE)** ボタンで照準と同じ数字のインベーダーを撃墜(同じ数字が複数並んでいる場合は自陣に近い方を優先的に撃墜)
5. 自陣に近い位置で倒すより、遠くで倒すほど高得点
6. 倒しきれず自陣(一番左のレーン)まで到達されるとライフが1減る(UFOは到達してもライフは減らない)
7. ライフが無くなるか、1ラウンドで FIRE を30回押すとゲームオーバー
8. **%** ボタンはゲーム中、効果音のON/OFFトグルになる

ルールは [CASIO SL-880 取扱説明書 (公式PDF)](https://support.casio.jp/storage/pdf/004/SL-880_WA_JA.pdf) の
「ゲーム機能(デジタルバトルゲーム)」の章を参考にしています。ライフの初期数など説明書に明記のない値は、
遊びやすさを考慮して独自に設定しています(デフォルト3ライフ)。

## 技術構成

- 素のHTML / CSS / JavaScript (ビルド不要、フレームワーク依存なし)
- 7セグメント風ディスプレイは CSS で自作 (`js/segmentDisplay.js`)
- PWA対応 (`manifest.json` + `sw.js` でオフライン動作・ホーム画面追加に対応)
- 外部ライブラリ・フォント等のネットワーク依存なし

```
calculator-invader/
  index.html          メイン画面
  css/style.css        電卓の見た目・LCD風表示
  js/
    segmentDisplay.js  7セグ描画ユーティリティ
    calculator.js      四則演算電卓ロジック
    game.js             インベーダーゲームロジック
    app.js               UI配線・入力ハンドリング
  manifest.json / sw.js  PWA設定
  test/                 ロジックの簡易回帰テスト(フレームワーク無し)
```

## ローカルでの動作確認

```bash
npm run dev
# http://localhost:3000 などで表示されたURLを開く
```

## テスト

```bash

```

## 見た目について

実機 SL-880 の写真(5列×6行のキー配置、シルバー筐体、GAME=青/税抜・税込=オレンジ/AIM・FIREは青枠、
ソーラーパネル風の黒いパーツ、液晶セグメントの角が斜めに落ちた形状など)を参考にレイアウト・配色・
7セグメント表示の形状を再現しています。ロゴ等の商標そのものは使用せず、独自のブランド表記(BLACK CAT)にしています。

キー配置に合わせて、電卓としての基本機能(√、+/−、独立メモリー M+/M-/MR/MC、税込/税抜)も実装しています。
「▶」キーは実機ではメロディ再生ボタンですが、本アプリでは未実装のため意匠のみ(無効化)です。

## 既知の簡略化

- パーセントキーの一部の特殊な挙動(例:差分%アップ表示)は簡略化
- 税率は固定10%(実機のような税率設定機能は無し)
- ライフの初期値・UFO出現確率・同じ数字が複数並んだ際に自陣に近い方を優先撃墜する仕様は、説明書に数値や詳細な記載が無いため独自のバランス・解釈
